# Hi, I'm Rei

I'm a web developer and creative technologist studying software engineering at 42 Porto. I build websites and interactive digital experiences, combining web development with animation and 3D work.

[Explore my portfolio](https://reinatch.website)

## Tools and interests

My web work uses React, Next.js, TypeScript, WordPress, and animation libraries including GSAP and Three.js. My studies also include systems programming in C and C++. I work with 3D modeling, animation, and texturing tools including Blender and Houdini.
